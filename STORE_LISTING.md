# Play Console answers (draft)

**App name:** Black Launcher
**Short description (80 chars):** Minimal black launcher. Clock, pinned apps, search. Ultra low battery.
**Full description:**
A minimal, pure-black home screen. Big clock, up to 6 pinned apps, swipe up to search all apps. No icons, widgets, ads or tracking. No internet permission. Double-tap to lock the screen (optional). Long-press an app to pin, hide, view info or uninstall. Long-press the clock to unhide apps.

**Category:** Personalization
**Data safety:** No data collected, no data shared.
**Permissions to declare:**
- REQUEST_DELETE_PACKAGES: lets the user uninstall an app from the app menu (user confirms in the system dialog).
- Device admin (force-lock only): double-tap-to-lock feature, optional, user activated.
