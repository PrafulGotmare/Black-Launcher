# Black Launcher

A minimal, pure-black Android launcher focused on privacy, tiny size and very low battery use.

- **No internet permission.** It cannot send any data anywhere.
- **About 40 KB.** No libraries, no ads, no tracking.
- **AMOLED black** home screen.
- Targets Android 16, works on Android 8.0+.

## Features
- Round and digital clocks (6 styles), adjustable size, thickness, alignment, 12/24h, date format
- Tap the clock for alarms, tap the date for calendar
- Pinned apps and named folders (e.g. "Jobs")
- Swipe up for app search
- Quick one-line note on the home screen
- Recent apps row and optional app icons
- Drag-anywhere layout editor and reorder sections
- Hide apps, double-tap to lock screen, burn-in shift

## ## Install

### Download the APK
1. Open the [Releases page](https://github.com/PrafulGotmare/Black-Launcher/releases) and download **BlackLauncher.apk** from the latest release.
2. Tap the file. If Android asks, allow your browser or Files app to **install unknown apps**.
3. If Google Play Protect shows a warning, tap **More details > Install anyway**. It appears because the app is not on the Play Store, not because a problem was found.
4. Go to **Settings > Apps > Choose default apps > Home app** and select **Black Launcher**.

### First use
- Long-press the clock or an empty spot on the home screen to open Edit mode.
- Tap **Customize** in the bottom bar for clock styles and other settings.
- For double-tap to lock, double-tap an empty spot once and tap **Activate**.

### Uninstall
1. Set your old launcher as the default home app again.
2. If you turned on double-tap lock, go to **Settings > Security > Device admin apps** and switch off Black Launcher.
3. Uninstall the app.

### Safety
The app has no internet permission, collects no data and contains no ads. Only install APKs from this repo's Releases page.
